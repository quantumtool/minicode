# MVP 产品需求文档：俄罗斯方块小游戏

## 1. 产品定位
一款轻量、可直接通过浏览器运行的俄罗斯方块小游戏，无需注册或下载，即开即玩，旨在提供经典、流畅的休闲娱乐体验。

## 2. 目标用户
- 所有熟悉或想体验经典俄罗斯方块的玩家
- 需要碎片化时间休闲的互联网用户（如上班族、学生）
- 偏好无广告打扰、快速启动的小游戏玩家

## 3. 核心使用场景
- 用户打开网页，游戏自动开始或点击“开始”后即刻游玩
- 在排队、等车、午休等碎片时间内进行3-5分钟的单局游戏
- 暂停后继续游戏

## 4. MVP 功能列表
| 功能模块 | 功能描述 |
|---------|---------|
| 游戏核心玩法 | 标准10×20方格棋盘；7种标准方块随机出现，从顶部下落 |
| 操作控制 | 键盘方向键：←/→左右移动，↑旋转，↓加速下落，空格直接落底 |
| 消行与计分 | 消行时闪烁动画并计分（单行100分，双行300分，三行500分，四行800分）；实时显示当前得分 |
| 下一个预览 | 在界面右上角显示下一个即将出现的方块形状，方便预判 |
| 游戏状态控制 | 开始/暂停（按P键或点击按钮）、游戏结束弹窗（显示得分，可点击重新开始） |
| 难度递增 | 每消10行，下落速度提升一个等级（初始每格0.8秒，最低0.1秒） |
| 音效反馈 | 消行、游戏结束时播放简单提示音（可选默认静音） |
| 界面最小化 | 仅包含游戏板、分数、下一个预览、暂停/重启按钮，无多余UI元素 |

## 5. 暂不开发的功能
- 用户注册/登录、排行榜、存档功能
- 多玩家对战、全球积分系统
- 皮肤、主题、自定义按键
- 手机触屏手势适配（仅限桌面键盘操作）
- 广告植入、内购道具
- 无限模式或特殊方块

## 6. 验收标准
- **核心功能正常**：方块正常下落、左右移动、旋转、加速、硬降；满行消除并计分；游戏结束（方块堆叠至顶部）后弹窗提示。
- **操作响应**：键盘响应延迟≤100ms，无键位冲突。
- **分数计算**：消行分数按规则正确累加，难度每10行提升一次，速度变化可感知。
- **预览准确**：下一个预览方块与实际落下的下一个方块完全一致。
- **暂停/继续**：按P键暂停时游戏冻结，再按恢复，不丢帧。
- **重启流畅**：游戏结束后点击重新开始或按回车键可立即重置棋盘与分数，无卡顿。
- **音效**：消行时播放短促提示音（音量适中），游戏结束时播放不同音效。
- **页面兼容**：在Chrome、Edge、Firefox最新版桌面浏览器中正常运行，分辨率1024×768以上显示完整。
